# 콘텐츠 확대 미리보기

콘텐츠 라이브러리와 휴지통의 썸네일을 누르거나 키보드로 선택하면 큰 미리보기 창을 연다. 이미지는 화면 안에서 원래 비율을 유지하며 전체를 보여 주고, 영상은 기본 컨트롤로 재생한다. 파일 이름은 텍스트로 출력한다.

닫기·Esc·배경 클릭으로 돌아온다. 창을 닫으면 이미지 src를 제거하고 영상 재생·소스를 중단해 큰 미디어 자원을 유지하지 않는다. 휴지통 이동·복원·삭제 단추는 확대와 별개로 동작한다. 미리보기 실패는 창 안에서 안내한다.

검증: `scripts/smoke-content-trash.cjs`에서 파일명 이스케이프, 큰 이미지, 원본 비율, Esc 해제, 320px 화면, 기존 휴지통·복원 흐름을 함께 확인한다.
