# 촬영 후 사진 꾸미기

폰 기본 카메라 촬영 → 사진 확인 → 등록. 촬영 사진과 갤러리 사진 모두 `사진 꾸미기`를 눌러 선택적으로 편집한다. 아무 효과 없이 원본으로 진행할 수 있다. 닫기·뒤로가기는 편집 중 변경을 버린다. 편집을 적용한 뒤에도 별도 등록 버튼을 눌러야 전송한다.

- 화면: 사진 공간이 남은 화면 높이를 채우고 전체 사진을 잘라내지 않고 표시한다. 뽀샤시 / 색감 / 프레임 / 꾸미기 / AI 탭을 제공한다. 강도 슬라이더와 원본 비교는 좌우 한 줄에 배치하고 저장 안내는 접어 둔다. 선택형 외부 AI 편집과 재사용 행사 장식은 [camera-ai.md](camera-ai.md)를 따른다.
- 뽀샤시: 강도 0~100, 5 간격. 중복된 켜기/끄기는 제거했다. 0은 뽀샤시 없음이며 색감·프레임은 유지한다. 원본 비교는 모든 효과를 잠시 숨기며 선택 강도와 효과를 변경하지 않는다.
- 색감: 없음 / 따뜻함 / 파스텔 / 필름 / 흑백. 프레임: 없음 / 화이트 / 폴라로이드 / 축하 / 필름컷 / 행사·날짜. 각각 하나를 선택해 뽀샤시와 함께 적용할 수 있다. 색감과 프레임에는 얼굴 탐지가 필요 없다. 축하·필름컷은 이미지 자산이나 추가 모델 없이 Canvas 도형으로 그린다.
- 행사·날짜 프레임은 현재 저장 행사명과 사진 날짜(없으면 한국 시간 오늘)를 기본값으로 채운다. 행사명은 32자까지, 날짜는 날짜 입력기로 수정할 수 있다. 사진 바깥의 여백에 행사명·날짜를 넣으며, 빠르게 입력할 때는 150ms 동안 변경을 모아 합성한다.
- 꾸미기는 하트 / 별 / 말풍선 / 문구를 최대 8개 배치한다. 사진에서 눌러 선택하고 드래그로 이동하며 크기·색상·15도 회전·삭제를 지원한다. 말풍선과 문구는 24자까지 편집한다. 키보드로는 선택 항목을 방향키로 옮기고 Delete로 지울 수 있다.
- 이동·크기·문구 변경은 화면 크기의 투명 Canvas에 벡터만 그린다(장치 배율 최대 2). 큰 사진의 합성 결과와 뽀샤시 버퍼는 다시 만들지 않는다. 선택 테두리는 저장하지 않는다. 저장 직전에 같은 벡터 그리기 함수를 최종 사진에 적용하며, 임시 이미지 복사 없이 기존 합성 버퍼를 사용한다.
- `photoEffects`에 행사 정보 및 꾸미기 종류·문구·정규화 좌표·크기·회전·색상을 저장한다. 원본 비교와 재접속 후 복원에서도 이 값들을 유지한다. 화면 선택용 ID는 보관 중복 방지 키에서 제외한다. 빈 문구는 저장 대상에서 제외한다.
- 처리 순서는 피부 보정 → 색감 → 프레임이다. 같은 합성 함수를 미리보기와 저장에 사용하고, 프레임은 사진 바깥에 여백을 더해 원본 내용을 자르지 않는다. 합성 후 긴 변도 최대 2048px로 제한한다.
- 얼굴 특징점으로 피부 마스크를 만들고 눈·눈썹·입을 제외한다. 얼굴 윤곽을 94%로 축소하던 처리를 제거하고, 각 얼굴 너비의 10%에 걸쳐 원본과 부드럽게 혼합한다. 눈·입 주변에는 별도의 작은 완충 폭을 두어 얼굴 가장자리와 눈·입 주변에 띠가 생기는 현상을 줄인다. 배경으로 마스크를 확장하지 않는다.
- 얼굴 크기에 맞춘 양방향 필터로 피부 결을 완화하고 중간 밝기와 그늘을 올린다. 얼굴형은 변경하지 않는다.
- 얼굴 분석과 보정 기준 이미지는 한 번만 계산한다. 슬라이더를 움직이면 원본과 보정 기준 이미지를 혼합하며 프레임당 한 번 미리보기를 갱신한다. 미리보기와 저장 사진은 동일한 강도를 사용한다.
- 강도는 `beautyLevel` 0~100 및 `beautyScale: 100`, 색감·프레임은 `photoEffects`로 저장한다. 기존 `beautyLevel` 1/2는 다시 편집할 때 35/70으로 읽고, 기존 미세 강도는 5 간격으로 반올림한다. 기존 대기 보정 파일은 사용자가 적용하기 전까지 변경하지 않는다.
- MediaPipe 얼굴 모델과 WASM은 서버에서 제공하고, 사진 분석·보정은 기기 안에서 실행한다. 얼굴 좌표는 저장·전송하지 않는다. 최대 8명을 탐지한다.
- 메모리 사용을 제한하기 위해 보정본의 긴 변은 최대 2048px, JPEG 품질 94%로 만든다. 촬영 날짜는 기존 메타데이터를 유지한다.
- 큰 JPEG/PNG는 헤더에서 크기를 읽어 `createImageBitmap`에 축소 크기를 지정한다. JPEG EXIF 방향을 반영하고, 지원하지 않는 형식·브라우저는 기존 이미지 디코딩 경로를 사용한다. 브라우저 내부 디코더의 실제 최대 메모리까지 보장하지는 않는다.
- 편집 시 원본을 한 번 디코딩해 원본 비교 Canvas와 얼굴 분석에 재사용한다. 전체 해상도 원본을 편집용 HTML 이미지로 다시 디코딩하지 않는다. 원본 파일 자체와 보관 경로는 유지한다.
- 원본/보정 픽셀 버퍼를 재사용하고 중간 평활화 배열은 보관하지 않는다. 합성 결과를 강도·색감·프레임별 현재 상태로 캐시해 탭 전환, 비교, 저장 시 재합성하지 않는다.
- 닫기 시 편집 작업을 취소하고 원본·미리보기·합성 Canvas를 1×1로 줄여 픽셀 메모리를 해제한다. 얼굴 모델도 닫는다. 이미 취소한 편집의 늦은 결과는 표시하지 않는다.
- 얼굴이 없거나 지원하지 않는 사진·기기·연결이면 원본으로 진행할 수 있다. 실패 시 보정을 적용했다고 표시하지 않는다.
- 보관하고 표출: 보정본 표출·공유·메일, 원본은 기존 비압축 보관 경로로 유지한다.
- 교회폴더에 저장만: 보정 적용 시 보정본을 저장한다. 보정 창과 카드에 표시한다.
- 보관없이 표출: 보정본을 표출·공유·메일로 보낸다.
- 원본 파일과 보정본은 전송 전까지 별도 보관한다. 새로고침 후에도 적용 상태와 보정본을 복원한다. 원본으로 되돌리면 보정 파일을 제거한다. 접수된 사진은 편집할 수 없다.

검증: `npm run test:camera-beauty` (실제 모델, 피부/배경 픽셀, 윤곽 완충, 큰 미리보기와 가로 조작줄, 비교, 재보정·복원, 꾸민 사진 게시·원본 보관, 얼굴 없는 사진의 색감/프레임, 합성 결과 저장·전송), `npm run test:camera-decorate` (행사 입력, 꾸미기 이동·크기·회전·삭제·8개 제한, 재합성 0회, 저장/복원/전송, 고배율 화면과 메모리 범위), `npm run test:camera-ui` (두 꾸미기 테스트 포함), `npm test`.
