# 사진 이메일 발송과 공유 (서버 1.5.0)

촬영 화면에서 **사진 받을 이메일**을 입력하면, 그때 올린 사진을 찍힌 분의 주소 한 곳으로 보낸다.
입력란은 선택이며, 서버에 메일 계정을 설정한 경우에만 나타난다. 설치형 모니터 프로그램은 바뀌지 않는다.

## 배포 전 설정

교회 Gmail 계정의 SMTP를 사용한다. 추가 비용은 없다. Railway는 **Pro 이상 요금제에서만** SMTP 포트(465/587)를 연다.

1. 발송에 쓸 Google 계정에서 2단계 인증을 켠다.
2. Google 계정 → 보안 → **앱 비밀번호**에서 새 비밀번호(16자리)를 만든다. 계정의 로그인 비밀번호는 쓰지 않는다.
3. Railway signage 서비스의 Variables에 아래 값을 넣는다. 실제 비밀번호를 소스 코드나 이 문서에 기록하지 않는다.

| 변수 | 값 |
| --- | --- |
| SMTP_USER | 발송 계정 주소 (예: `yebom@gmail.com`) |
| SMTP_PASS | 위에서 만든 앱 비밀번호 |
| MAIL_FROM_NAME | 보내는 사람 이름과 제목 머리말. 비우면 `예봄교회` |
| MAIL_DAILY_LIMIT | 하루 최대 발송 통수. 비우면 300 |
| SMTP_HOST / SMTP_PORT | 다른 메일 서버를 쓸 때만. 비우면 `smtp.gmail.com` / `465` |
| MAIL_FROM | 계정에 등록된 다른 보내는 주소를 쓸 때만 |

`SMTP_USER`와 `SMTP_PASS`가 없으면 기능이 꺼지고 촬영 화면에 입력란이 나오지 않는다.
개인 Gmail은 하루 약 500명, Google Workspace는 약 2,000명까지 보낼 수 있다. `MAIL_DAILY_LIMIT`은 그보다 작게 둔다.

## 동작

- 메일은 **본인 취소 시간(표출 방식 설정의 "본인 취소")이 지난 뒤** 발송한다. 그 전에 사진을 취소하면 메일에서도 빠진다.
- 촬영 화면의 **메일 보내지 않기**는 메일만 취소한다. 사진은 화면과 보관함에 남는다. 주소를 잘못 넣었을 때 쓴다.
- 한 사람이 같은 주소로 취소 시간 안에 올린 사진은 한 통에 첨부한다. 12장 또는 약 18MB를 넘으면 나누어 보낸다.
- 받는 주소는 한 곳만 받는다. 형식이 틀리면 사진을 접수하지 않고 돌려보낸다. 자주 틀리는 도메인 오타는 화면에서 짚어 준다.
- 발송에 실패하면 1분부터 최대 30분 간격으로 6번까지 다시 시도한 뒤 포기한다.
- 보관함에서 사진을 삭제하면 아직 보내지 않은 메일에서도 뺀다. "화면에서 내리기"와 "라이브 즉시 종료"는 메일을 막지 않는다.
- 관리 화면의 **라이브 송출** 탭("현재 라이브 현황")에 오늘 발송 수, 대기 수, 최근 오류가 표시된다. 받는 주소는 표시하지 않는다.

## 개인정보

- 받는 주소와 발송용 사진 복사본은 `DATA_DIR/photo-mail/`에 두고, 발송 완료·취소·포기 시 삭제한다.
  주소는 사진 보관함, Drive 설명, 서버 로그, 관리 API에 남기지 않는다.
- 촬영 화면은 받는 주소를 기억하지 않는다. 사진을 올리면 입력란을 비운다(다음 분에게 잘못 가지 않도록).
- **Gmail은 SMTP로 보낸 메일을 발송 계정의 보낸편지함에 남긴다.** 주소와 사진이 그곳에 남으므로,
  발송 전용 계정을 쓰거나 보낸편지함을 정기적으로 비운다. 없는 주소로 보낸 메일의 반송 알림도 이 계정으로 온다.
- 이미 발송된 메일은 회수할 수 없다.

## 카카오톡 등으로 공유

사진을 올린 뒤 나오는 **카카오톡 등으로 보내기** 버튼은 휴대폰의 공유 창을 연다. 사진은 서버를 거치지 않고
촬영한 폰에서 바로 넘어가며, 메일 설정과 무관하게 동작한다. 파일 공유를 지원하지 않는 브라우저
(카카오톡 안의 브라우저, 구형 브라우저)에서는 버튼이 나타나지 않는다. 결과 화면을 닫으면 다시 공유할 수 없다.

## 검증

`cd host; npm test`의 `photo-mail.test.js`가 주소 검증, 묶음 발송, 취소, 재시도·재시작, 하루 한도,
실제 SMTP 접속(로컬 가짜 서버)과 서버 연동을 확인한다. 실제 Gmail 발송과 휴대폰 공유 창은 운영 환경에서 별도로 확인한다.
