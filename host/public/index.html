모니터 표출 접수
폰으로 찍은 사진이 지정한 모니터에 즉시 뜹니다. 편성표는 뒤에서 계속 재생되며, 새 사진이 일정 시간 없으면 저절로 편성표로 돌아갑니다. 평소에는 꺼 두고 행사 때만 켜는 것을 권합니다.
폰 링크

이 링크를 사진 올릴 사람에게 전달하세요

사진은 교회사진 루트의 연도·행사 폴더에 보관할 수 있습니다. 모니터 표출 접수와 별도로 제어합니다.

카톡방에 붙여넣거나 QR로 보여주면 됩니다. 폰에서 열고 홈 화면에 추가하면 앱처럼 씁니다.

촬영 암호를 통과한 단말만 사진을 올릴 수 있습니다. 접수를 닫아도 기존 사진과 편성표는 유지됩니다. 문제가 생기면 아래 라이브 즉시 종료 로 화면에서 내리고, 촬영 단말 전체 로그아웃으로 암호를 다시 입력하게 할 수 있습니다.

표출 방식 설정

풀스크린(히어로) 시간

새 사진이 혼자 크게 뜨는 시간. 대기 사진이 있으면 아래 단축 시간이 적용되고, 3장 이상 한꺼번에 오면 풀스크린을 건너뛰고 바로 배치됩니다.

편성표 복귀

이 시간 동안 새 사진이 없으면 편성표로 돌아갑니다. 돌아간 뒤 코너에 작게 남는 시간도 정할 수 있습니다(0이면 바로 사라짐).

동시 표출 장수

그리드 최대 칸 수. 장수에 따라 1장=풀스크린, 2장=좌우, 3장=3분할, 4장=2x2로 자동 배치됩니다.

보관 / 취소

아래 시간은 화면용 임시 파일의 유지 시간입니다. 사진과 문구는 별도의 사진 보관함에 남습니다. 업로더가 취소하면 보관함에서도 삭제됩니다. 받는 이메일을 입력한 사진은 본인 취소 시간이 지난 뒤에 발송됩니다.

화면에는 메시지만 나가고, 올린 사람은 여기에만 기록됩니다(익명 장난 방지).

클라이언트 설치

💻 PC 전용 클라이언트 (Electron)

전체화면 키오스크 + 오프라인 캐시 재생. 압축 해제 후 install.bat 실행 한 번으로 설치·부팅 자동실행까지 완료됩니다. 신규 설치·업데이트 겸용 — 기존 PC는 같은 폴더에 덮어쓰고 install.bat만 다시 실행하면 자동으로 업데이트됩니다(설정·캐시 유지).

⬇ 설치 파일 다운로드 (zip)

⚠ Windows 11에서 install.bat이 "애플리케이션 제어 정책"으로 차단되면: 압축 풀기 전 zip 오른쪽클릭 → 속성 → 차단 해제. 그래도 막히면 설정 → Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 제어 끄기 (동봉 사용설명서 참고).

🌐 웹 플레이어

브라우저에서 바로 재생. 설치 없이 테스트하거나 간단히 띄울 때 사용합니다.

클라이언트 등록 초기화

등록·승인된 모든 클라이언트를 지웁니다. 연결된 클라이언트는 대기 화면으로 돌아가 재승인이 필요합니다. (사이트·편성표는 유지)

전체 초기화

클라이언트 + 사이트 + 편성표를 모두 비웁니다. 완전히 새로 시작할 때만 사용하세요. (콘텐츠 파일은 유지)
